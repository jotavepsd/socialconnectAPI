📦 Entrega e Validação

✅ Checklist de Sucesso:
  • [ ] O comando mvn test executa com BUILD SUCCESS.
  • [ ] Os testes seguem o padrão AAA com comentários // ARRANGE, // ACT, // ASSERT.
  • [ ] O teste de integração usa o Testcontainers (verificar logs do Docker).
  • [ ] Nomes dos métodos são descritivos (ex: deveRetornar400QuandoDataFutura).
⚠️ Atenção: Certifique-se de que o Docker Desktop (ou Docker Engine) está rodando na sua máquina antes de executar os testes de integração, pois o Testcontainers precisa dele para subir o PostgreSQL.
